### Cardiac Surgery & Mortality Risk Analysis Dashboard (2020)

An interactive dashboard analysing surgery volume, discharge outcomes, operation types, and mortality risk trends across surgeons.

---

**Project Description:**
This project analyses a cardiac surgery dataset from 2020 to evaluate surgical activity, patient outcomes, and mortality risk predictions across different surgeons and procedure types. The dataset contains 1,335 surgical procedures with information on patient characteristics, procedure types, surgeon names, predicted mortality risk from two statistical models, and actual discharge outcomes.

The objective of the analysis was to validate key clinical variables, explore surgical activity patterns, and compare predicted mortality risk with actual outcomes. Using Microsoft Excel, the data was cleaned, validated, and analysed using PivotTables, calculated metrics, and interactive visualisations.

An interactive dashboard was developed to provide a clear overview of hospital surgical performance, including total surgeries performed, overall mortality rate, the most common procedure type, and surgeons associated with higher risk levels. Filters were also added to allow users to explore results by admission date, procedure type, and patient discharge status.

This project demonstrates how structured data analysis and visualisation can support clinical performance monitoring and data-driven decision-making in healthcare environments.
